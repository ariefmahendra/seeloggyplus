# SeeLoggyPlus 0.6.5

## Overview
This patch release removes the leftover console window on Windows and makes a
fresh release visible to update checks immediately after it is published.

## Fixed
- **No more background terminal**: starting a legacy installation or choosing
  "Restart to update" no longer leaves a `cmd` window open for the whole session.
  The app now restarts itself directly with `javaw`, and on startup it repairs an
  old root `launcher.bat` that still ran `java.exe` in the foreground. A launcher
  that already starts the app with `javaw` (or a customised one) is left untouched.
- **Update check right after a release**: the default update manifest is now fetched
  from `https://github.com/ariefmahendra/seeloggyplus/releases/latest/download/update-manifest.json`
  (`Cache-Control: no-cache`) instead of the `raw.githubusercontent.com` endpoint,
  which is cached for five minutes. A release published moments ago is now detected
  by the first check, without waiting for the cache to expire.

## Tests
- Added `UpdateRelauncherTest` (hidden `javaw` restart, active-version jar,
  `max.memory.gb` handling) and `RootLauncherInstallerTest` (legacy launcher healed,
  custom/`javaw` launcher preserved, no-op without a staged launcher).
- Added `UpdateServiceImplTest.defaultManifestUrlUsesTheUncachedLatestReleaseEndpoint`
  to pin the manifest endpoint.
- All 510 headless tests pass, and the production startup smoke test succeeds.

## Upgrade notes
- Users update normally. The launcher repair happens automatically on the first
  start of 0.6.5; the terminal window from an already running session closes when
  that session is closed.
