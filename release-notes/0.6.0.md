# SeeLoggyPlus 0.6.0

## Overview
A feature release focused on real-world SSH usage and a cleaner, more consistent UI:
private-key authentication with host-key verification, nested server groups in File
Management, and a recent-files tree grouped per server.

## Features
- **Private-key authentication** - each server can use a password or a private key file
  (with an optional encrypted passphrase). Modern keys (ed25519, ecdsa, rsa-sha2) are
  supported via the maintained JSch fork.
- **Host-key verification** - the first time a host is contacted the app shows the key
  fingerprint and asks to trust and save it (`.data/known_hosts`). A changed host key is
  always refused with a clear MITM warning.
- **Server groups in File Management** - the Locations panel is a WinSCP/MobaXterm-style
  tree. Groups persist (even when empty), can contain other groups, and support New,
  Rename, Delete, Move to group and drag & drop. Dragging never connects; a location
  opens on click or Enter.
- **Recent Files tree** - recent entries are grouped per server under expandable nodes;
  search matches server name, file name and path (all words).
- **Clear connect errors** - failures report the real reason (missing key file, auth
  failure) instead of a generic "check credentials" message.
- **Silent Windows launcher** - `SeeLoggyPlus.vbs` starts the packaged app without a
  terminal window; `launcher.bat --console` remains for diagnostics.
- **Double-click preference** - choose Open/Download (default) or Tail for files in
  File Management.

## Improvements
- Server Management is CRUD-only; grouping and favorites moved out of it.
- Buttons and dropdowns consistently follow the active theme with readable
  focus/hover/pressed states; dropdown selection is neutral (light in Graphite/Light).
- The File Management left panel is compact (icon action bar, collapsible Favorite
  folders) and the footer no longer reports cache internals.
- Reloading an active remote tail reconnects in the background; the window stays
  responsive.
- The Server editor form scrolls and always keeps Test Connection / Cancel / Save
  visible; the Browse button is compact.

## Database
- Schema v3 adds the `server_groups` table (existing group names are backfilled).
- Schema v4 adds `auth_type`, `key_path` and `key_passphrase` to `ssh_servers`.
- Both migrations are additive, idempotent, transactional and create an automatic
  backup before running.

## Tests
- 472 headless tests green, including new coverage for migrations, auth persistence and
  encryption, known-hosts trust-on-first-use, connect flow, editor UI, theme contrast,
  grouping/drag-and-drop and reload responsiveness.

## Upgrade notes
- No configuration changes required. Existing servers keep password authentication.
- To switch a server to key auth: Server Management  Edit  Authentication: Private key
  and pick the private key file (not the `.pub`).
