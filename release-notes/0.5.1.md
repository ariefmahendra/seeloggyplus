# SeeLoggyPlus 0.5.1

## Overview
Bug-fix release for the self-update feature: it no longer searches folders
recursively and now uses the application data folder that already exists.

## Fixes
- **Self-update download location** — updates are downloaded and staged under the
  application data folder (`<data>/updates`) instead of the system temp directory, so
  they use the folder the app already owns.
- **No recursive folder search** — the installer finds `seeloggyplus.jar` from the
  known package layout (the optional wrapper folder is stripped first) rather than
  walking the extracted tree.
- **Correct install root (blue/green)** — when the app runs from
  `versions/<version>/seeloggyplus.jar`, the root is folded back to the real
  installation folder, so subsequent updates stage and activate in the right place.

## Tests
- Added `UpdateLayoutTest`.
- Extended `UpdateInstallerTest` (jar is not searched recursively) and
  `UpdateDialogControllerTest` (staging directory lives in the app data folder).

## Upgrade notes
- No configuration changes required.
