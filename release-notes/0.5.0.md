# SeeLoggyPlus 0.5.0

## Overview
Feedback release: fixes the "version shows DEV" build issue and the recent-file /
tail-mode confusion, and adds a fully light theme so users who prefer an all-light
interface can switch to it.

## Added
- **All-light theme** — a third theme with light menu bar, toolbar and status bar
  (not just light content), selectable from **Preferences → Theme**:
  Graphite (default) / Light / Dark.

## Changed
- Interactive states (hover / selected / pressed / focus) now follow the active theme
  via shared accent tokens. In the **Light** theme the accent is **blue** (matching the
  detail panel); graphite and dark keep their existing look.
- Toolbar buttons no longer grow by a pixel when focused or clicked — the focus ring
  space is reserved, only its colour changes.

## Fixed
- **Release version** — packaged builds no longer report `vDEV`. `version.properties`
  is generated into a declared, cache-correct resource directory so it is always
  included in releases.
- **Recent files** — the list now remembers whether a file was last opened normally or
  in live **tail**, and reopens it the same way. A previously tailed entry no longer
  silently switches to download mode.
- **Remote files** — opening a file that is already streaming reuses its existing tab
  instead of downloading it again, which previously failed with an SSH channel error.
- Removed remaining hard-coded component colours so every component follows the
  selected theme.

## Tests
- Added `AppVersionTest`, `RecentFileModeRepositoryTest`, `RecentFileOpenModeTest`,
  `LightThemeTest`, `ThemeTokensTest`, `ThemeComponentParityTest`.
- `ThemeTokensTest` guards token parity across themes and forbids hard-coded colours in
  component CSS; `ThemeComponentParityTest` checks every theme's chrome and interactive
  states.

## Upgrade notes
- No configuration changes required. Existing installs default to the graphite theme;
  pick **Light** or **Dark** in Preferences if preferred.
