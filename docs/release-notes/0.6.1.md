# SeeLoggyPlus 0.6.1

## Overview
First published build of the 0.6 line. The 0.6.0 release workflow failed before
publishing, so 0.6.1 ships the exact 0.6.0 feature set (private-key authentication,
host-key verification, nested server groups, grouped recent files, clearer errors and
a responsive UI) plus CI reliability fixes.

## Fixed
- **Release pipeline**: failing tests are now summarized on the workflow run page, so
  a red run can be diagnosed without access to the raw logs.
- Two UI test assertions were hardened for CI machines:
  - remote-tail reload responsiveness now uses a latch instead of wall-clock sleeps;
  - the Browse button size assertions use platform-tolerant tolerances.

## Features (same as 0.6.0)
- Private-key authentication (ed25519 / ecdsa / rsa-sha2) with optional encrypted
  passphrase.
- Host-key verification with fingerprint confirmation and a hard refusal when a saved
  host key changes.
- Nested server groups in File Management (New / Rename / Delete / Move to group and
  drag & drop; dragging never connects).
- Recent Files grouped per server with expandable nodes.
- Real connect-failure reasons, responsive remote-tail reload, silent Windows launcher,
  and the double-click Open/Tail preference.

## Tests
- Full headless suite green before release.

## Upgrade notes
- No configuration changes required. Existing servers keep password authentication.
