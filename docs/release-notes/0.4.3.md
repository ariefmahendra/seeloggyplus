# SeeLoggyPlus 0.4.3

## Overview
Maintenance release focused on the log viewer's keyboard experience.

## Fixes
- **Log viewer** — Up/Down (and PageUp/PageDown/Home/End) keys now move the log viewer
  even when focus is not on the canvas. Navigation is installed as a scene-level key
  filter and still respects text inputs, lists/tables and the detail editor.

## Tests
- Added `LogViewerArrowKeyNavigationTest`.

## Upgrade notes
- No configuration changes required.
