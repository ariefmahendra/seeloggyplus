# SeeLoggyPlus 0.6.2

## Overview
First published build of the 0.6 line. The 0.6.0 and 0.6.1 release workflows failed in
the CI `test` job, so 0.6.2 ships the same feature set with a platform-independent test
assertion.

## Fixed
- **CI test job**: `UnifiedFileManagerDialogControllerTest.testServerConnectionFailure`
  assumed the local home directory is never `/`, which is wrong on Linux. It now
  asserts the failed connect falls back to a local location and that the path shows the
  local home (valid on Windows and Unix).
- The release workflow also publishes failing test names to the run summary, and the
  Gradle `testSummary` prints them after the summary block.

## Features (same as 0.6.0)
- Private-key authentication (ed25519 / ecdsa / rsa-sha2) with optional encrypted
  passphrase.
- Host-key verification with fingerprint confirmation and a hard refusal when a saved
  host key changes.
- Nested server groups in File Management (New / Rename / Delete / Move to group and
  drag & drop; dragging never connects).
- Recent Files grouped per server with expandable nodes.
- Real connect-failure reasons, responsive remote-tail reload, silent Windows launcher,
  and the double-click Open/Tail preference.

## Tests
- Full headless suite green before release.

## Upgrade notes
- No configuration changes required. Existing servers keep password authentication.
