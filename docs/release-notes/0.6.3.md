# SeeLoggyPlus 0.6.3

## Overview
Patch release that makes self-update work again from older versions. The 0.5.1
installer rejected the 0.6.2 package because it contained `SeeLoggyPlus.vbs`, a file
older installers do not allow.

## Fixed
- **Self-update from 0.5.x**: portable packages no longer ship `SeeLoggyPlus.vbs`.
  The app recreates the silent Windows launcher in the installation root on startup
  when it is missing, so updates from 0.5.x stage and activate normally again.
- **Self-update compatibility rule**: update packages may only contain entries that
  older released installers accept; new helper files are created at runtime instead of
  being added to the zip.

## Tests
- Added `SelfUpdateEndToEndTest` (real download stream → stage → activate → health →
  rollback; failed download leaves the installation untouched; package entries pinned
  against the 0.5.x whitelist).
- Added `SilentLauncherInstallerTest`; `WindowsLauncherTest` now guards that the
  silent launcher is never packaged.

## Upgrade notes
- Users on 0.5.x can update straight to 0.6.3.
- `SeeLoggyPlus.vbs` appears in the installation folder after the first start of the
  new version (no manual step needed).
