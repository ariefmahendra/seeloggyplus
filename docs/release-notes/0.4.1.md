# SeeLoggyPlus 0.4.1

## Overview
A focused maintenance release that resolves several UI defects reported after the
0.4.0 design overhaul and adds regression tests so they cannot recur.

## Fixes
- **Find in Files** — wider, easier-to-grab scrollbars; the selected/highlighted preview
  line now uses the shared selection colour with readable, theme-matched text in both
  light and dark modes.
- **Log viewer** — restored the scrollbar step (up/down) buttons so a single row can be
  stepped by click again.
- **Main view** — horizontal scroll over the tab header moves the selected tab; toolbar
  toggle icons (Tail, Smart Follow) now keep the theme colour in every state.

## Tests
- Added `ScrollBarDefectTest`, `PreviewSelectionThemeTest`, `TabScrollSwitchTest`,
  `ToolbarToggleIconThemeTest`.

## Upgrade notes
- No configuration changes required.
